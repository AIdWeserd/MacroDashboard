# Контекст модулей src

Этот файл дополняет корневой `AGENTS.md` для работы внутри `src/`.

## Карта загрузчиков

| Модули | Назначение |
| --- | --- |
| `fetch_fred.py`, `fetch_fred_cpi.py`, `fetch_fred_gdp.py`, `fetch_fred_unemployment.py` | Макроряды, CPI, рост ВВП и безработица FRED; `FRED_API_KEY` |
| `fetch_imf.py` | IMF WEO через `imf-reader`; годовые метрики для fallback |
| `fetch_eurostat.py`, `fetch_eurostat_unemployment.py`, `fetch_eurostat_quarterly.py` | HICP, безработица и квартальные метрики Европы |

| `fetch_china_fiscal.py`, `fetch_china_trade.py`, `fetch_china_gdp.py` | Бюджет, текущий счёт SAFE и ВВП; fiscal вызывает trade и gdp |
| `fetch_nifd_report.py` | Скачивание PDF NIFD и извлечение квартального долга Китая |
| `fetch_china_cpi.py`, `fetch_china_unemployment.py` | Месячные показатели Китая |
| `fetch_singapore_mom.py`, `fetch_singapore_cpi.py`, `fetch_singapore_gdp.py`, `fetch_singapore_quarterly.py` | Показатели Сингапура |
| `fetch_brazil_ibge.py`, `fetch_brazil_cpi.py`, `fetch_brazil_gdp.py`, `fetch_brazil_quarterly.py` | IBGE/SIDRA и квартальные показатели Бразилии |
| `fetch_uk_ons.py`, `fetch_uk_quarterly.py` | CPI и квартальные показатели Великобритании |
| `fetch_japan_cpi.py`, `fetch_japan_quarterly.py` | CPI и квартальные показатели Японии; e-Stat требует `ESTAT_APP_ID` |
| `fetch_korea_cpi.py`, `fetch_korea_quarterly.py` | ECOS CPI и квартальные данные IMF DSBB |
| `fetch_india_cpi.py`, `fetch_india_unemployment.py`, `fetch_india_gdp.py` | Показатели Индии; GDP обращается к MoSPI MCP по HTTP |
| `fetch_canada_*`, `fetch_australia_*`, `fetch_switzerland_*`, `fetch_turkey_cpi.py` | Национальные CPI, безработица/ВВП и квартальные показатели в пределах реализованных модулей |
| `fetch_policy_rates.py` | Ставки ЦБ из нескольких источников; Австралия использует `fastmcp` и команду `rba-mcp` |

Точные URL, серии, методики и ограничения смотреть в конкретном модуле и
`SOURCES.md`. Например, ECOS сейчас использует строку `sample`, а в MoSPI GDP
список финансовых лет задан явно; не считать покрытие и доступность бесконечными.

## Контракты данных и интеграция

- Загрузчики обычно возвращают `pandas.DataFrame`; сетевые ошибки могут давать
  пустой DataFrame или исключение. Планировщик `_step()` сохраняет только
  непустые результаты, ловит исключения и продолжает следующие шаги.
- Единой схемы всех загрузчиков нет. Проверять ожидаемые столбцы в паре
  `save_*`/`load_*` и потребителях `build_summary.py`, `app.py`.
- Страны обозначаются кодами вроде `US`, `CN`, `EU`; нормализованные ряды обычно
  используют `date`, `country` и столбцы показателей. IMF использует
  `country, year, metric, value`; календарь — `datetime` в UTC.
- `storage._save_df()` использует `to_sql(..., if_exists="replace")` и пропускает
  пустые результаты. `save_china_fiscal()` отдельно объединяет старые и новые
  данные по датам с последними непустыми значениями. Не заменять его общей
  перезаписью без проверки последствия для истории.
- `_load_df()` возвращает пустой DataFrame при исключениях чтения. Отсутствие
  данных в UI может означать отсутствие таблицы или ошибку чтения; учитывать
  это при диагностике.
- NIFD хранит PDF по относительному пути `data/nifd_reports`; запускать из корня.
- Новый загрузчик подключать в `scheduler.py`: импорт, пара save/load в storage,
  шаг в `GROUPS`, потребитель в сводке/интерфейсе и описание источника.

## Сводка, даты и снимки

- `build_summary.py` задаёт `COUNTRY_ORDER` и отображаемые названия для 17 стран.
  `config.COUNTRIES` содержит другой, более узкий список; не считать его
  единственным перечнем стран интерфейса.
- `build_summary(year=None, month=None)` выбирает значения по границе периода,
  сочетает национальные/квартальные источники с IMF fallback. Сохранять
  сопутствующие столбцы `*_date` при добавлении или замене метрик.
- Метки дат используются в `app.parse_date_label()` и `value_if_in_period()`:
  месяцы на русском, кварталы `Qn YYYY`, годовые метки IMF. Изменять формат
  только вместе с потребителями.
- `snapshot.py` хранит long-формат в `summary_snapshots`; ключ — ISO-неделя,
  страна и метрика. Повторный запуск в той же неделе не меняет снимок без
  `force=True`. Предыдущий снимок берётся строго из более ранней недели.
- Список сравниваемых показателей задан в `SUMMARY_METRICS`; ставки туда
  сейчас не входят. Добавление столбца сводки не подключает его автоматически
  к недельной подсветке.

## Проверка изменений

Парсеры проверять на реалистичных ответах с отсутствующими полями, числами и
датами; расчёты — на известных единицах и границах кварталов/лет. Не подменять
ошибки источника правдоподобными выдуманными значениями. Проверять уникальность
строк, сортировку и сохранение истории там, где они нужны потребителям.
Для сетевых проверок выбирать конкретную группу планировщика и сообщать о
реальном результате загрузки; успешный выход CLI не гарантирует успех всех шагов.
