Макродашборд: динамические периоды и логика годовых/квартальных данных

Комплект основан на присланном src.zip плюс подтверждённых пользователем версиях
build_summary.py (годовые IMF WEO, прогноз текущего года) и Eurostat EA19/EA20/EA21.
Пять модулей Eurostat повторно менять не нужно: их код не входит в этот ZIP.

Файлы в архиве — ПОЛНЫЕ модули, не патчи. Сохранить резервную копию
имеющихся файлов src, затем заменить только файлы из этого ZIP.

После замены:
  python test.py

Тесты без сети, чтения/записи SQLite и scheduler.
Не запускать плановое обновление до проверки тестов.

Основные правила:
- Годовой IMF: fallback, исторические годы обозначены как годовые данные,
  текущие/будущие как прогноз.
- Завершённый календарный год: в декабре официальные годовые/IMF,
  не Q4 как замена года.
- Индия: MoSPI GDP/IMF WEO в финансовых годах апрель-март;
  в основной таблице для ВВП отображается FY... Qn, не календарное Qn.
- Bloomberg Excel — только при отсутствии подходящего официального квартала
  текущего года, не используется за прошлые завершённые годы.
- Периоды динамичны от даты запуска, без верхней границы 2026/2030.
- Даты начала исторических рядов и базовый год статистического индекса
  остаются фиксированными намеренно; это не верхние границы обновления.
- Российские публикации Росстата/GFS подбираются по схеме имён с запасными
  проверенными ссылками. Если схема именования/страница публикации изменится,
  нужно обновить адаптер получения XLSX. Код не выдумывает отсутствующие данные.
- Автоматической проверки сети с реальными сайтами в этот раз не было.

Внимание: данные WEO Индии маркируются по FY, начинающемуся в году year.
Если конкретная выпускаемая серия IMF использует иное индексирование,
это нужно скорректировать по метаданным этого ряда; значения не пересчитываются.
