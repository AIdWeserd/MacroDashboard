# Macro Dashboard — установка на новый компьютер

**Версия инструкции: 26 октября 2026 года.** Применяется к рабочему проекту Macro Dashboard (Python, Streamlit, SQLite). Не относится к отдельному хакатону.

## 1. Что потребуется

- Windows 10/11 и PowerShell; проверенное рабочее окружение — **Python 3.12.5**.
- Папка с **полной актуальной версией** исходников проекта (включая `app.py`, `config.py`, `scheduler.py`, `src/`, `requirements.txt` и `scripts/`). Это может быть приватный репозиторий или архив, переданный владельцем; URL репозитория в проекте не задан.
- Интернет для получения данных из FRED, Eurostat и национальных источников. Некоторые источники могут быть недоступны из конкретной сети.
- API-ключи **FRED**, **BEA** и японского **e-Stat**, если нужны соответствующие загрузчики. Значения ключей получать самостоятельно у поставщиков; реальные ключи в репозиторий не класть.
- Для ручного импорта Bloomberg — доступ к разрешённому Excel Add-in и подготовленной выгрузке (не требуется для старта интерфейса).

## 2. Размещение проекта

Распакуй или склонируй **свой** актуальный экземпляр проекта в удобную папку, например:

```powershell
cd C:\MyProjects\CB\Macro_dashboard
```

Все команды в документации выполняются **из корня проекта**, то есть там, где находится `scheduler.py`.

## 3. Создание окружения и зависимости

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

Если команда `py -3.12` не найдена, установи Python 3.12 и убедись, что он доступен из терминала. Пакетам `rba-mcp` и `fastmcp` для некоторых источников могут понадобиться дополнительные условия сети. Если PowerShell запрещает запуск `Activate.ps1`, настрой политику запуска для текущего процесса или вызывай `.venv\Scripts\python.exe` без активации.

**Отдельно для PDF-экспорта:** пакет Playwright включён в `requirements.txt`,
но браузер Chromium нужно установить после зависимостей:

```powershell
python -m playwright install chromium
```

На Linux/WSL при отсутствии системных библиотек браузера:
`python -m playwright install --with-deps chromium`.
Без Chromium интерфейс показывает ошибку PDF-экспорта и блокирует скачивание;
остальные форматы продолжают работать. PyMuPDF для российских PDF и xlrd для
официальных XLS также включены в `requirements.txt`.

**Важно:** `requirements.txt` в рассмотренной версии проекта не фиксирует точные версии пакетов. Поэтому чистая установка в другой день не гарантирует воспроизведение среды один в один. При переносе работающего экземпляра желательно сохранить `python -m pip freeze` в отдельный локальный файл без секретов и проверить совместимость.

## 4. Настройка конфигурации

Создай в корне файл `.env` (или задай переменные окружения):

```dotenv
FRED_API_KEY=вставь_свой_ключ
BEA_API_KEY=вставь_свой_ключ
ESTAT_APP_ID=вставь_свой_ключ
```

Не используй эти строки буквально: нужны реальные ключи. `.env` не отправлять в публичные репозитории и архивы. В `config.py` через переменную `DB_PATH` задаётся путь к рабочей базе SQLite; **название проекта не совпадает с названием файла БД**. `data/` создаётся конфигурацией при обращении к ней.

## 5. База данных: перенос или создание

- **Если переносишь существующий проект с историей:** получи у владельца актуальную согласованную резервную копию SQLite и размести её по пути `config.DB_PATH`. Простое копирование во время записи может быть небезопасно: предпочтителен `sqlite3.backup()` либо остановка пишущих процессов.
- **Если база отсутствует:** интерфейс не будет содержать историю, пока не будут выполнены нужные загрузчики. Сначала проверь группы по `--dry-run`, затем выполни доступные группы. Полный сбор истории зависит от ключей и внешних сайтов; успешность не гарантируется.
- Не используй резервную базу из старого ZIP как «последнюю» без сверки дат.

## 6. Первая проверка установки

```powershell
python -m compileall -q app.py src
python scheduler.py --list
python scheduler.py --dry-run
streamlit run app.py
```

При успешном старте открой `http://localhost:8501`. Пустая таблица при отсутствующей базе — не ошибка установки зависимостей. `--dry-run` **не обращается к API и не записывает данные**.

Для первоначального наполнения рекомендуется запускать нужные группы по отдельности, например:

```powershell
python scheduler.py fred
python scheduler.py eurostat
```

Проверь `[SUMMARY]`, `[FINISH]` и код завершения. Полный запуск `python scheduler.py` обращается к **59 этапам** и может возвращать код `1` или `2`, когда внешние сервисы недоступны. Это не повод стирать старую базу.

## Локальные регрессионные проверки

```text
python -m unittest discover -s tests -v
```

Проверки используют искусственные ответы и временную SQLite; ключи и полная
сетевая загрузка не требуются.

## Контейнеры и деплой

Общий каталог данных задаётся `MACRO_DATA_DIR` (по умолчанию `data/` проекта).
В контейнерах web и updater используют `/app/data`; SQLite и PDF NIFD остаются
в постоянном каталоге. Образ содержит зависимости из `requirements.lock` и
Chromium для PDF-экспорта; его браузер доступен пользователю приложения UID 10001.
