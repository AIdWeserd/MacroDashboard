# Контекст операционных команд

Python-команды запускать из корня через `python -m scripts.<команда>`.
`update_data` и `deploy.sh` рассчитаны на Linux; локальная разработка UI возможна
и на Windows. Общие контракты описаны в `docs/ARCHITECTURE.md`.

- `update_data` вызывает scheduler отдельным процессом. Сохранять блокировку,
  timeout и завершение дочерней группы при SIGTERM. Ручной scheduler не блокируется.
- `backup` использует SQLite backup API и не перезаписывает существующую копию.
  Не заменять на файловое копирование открытой базы.
- `check_app` выполняет AppTest без сетевого календаря. В проверках задавать
  временный MACRO_DATA_DIR, чтобы не обращаться к production SQLite.
- `deploy.sh` проверяет digest, сериализует релизы flock и восстанавливает прежний
  стек при ошибке. Проверять удачный, неудачный и первый деплой.
  При переходе с ручного запуска current может указывать на manual-baseline:
  его image — локальный тег. Внутренний rollback должен поддерживать этот случай.
  Прямой запуск deploy.sh с локальным тегом по-прежнему не разрешён.
- Сетевой refresh не включать в CI; права данных согласованы с UID/GID 10001.
