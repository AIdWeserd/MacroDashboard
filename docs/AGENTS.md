# Контекст документации

`ARCHITECTURE.md` объясняет модули и каталоги, `DEPLOYMENT.md` — настройку Ubuntu,
GitHub Actions, GHCR, SSH, host:port, обслуживание и откат.
`MANUAL_DEPLOYMENT.md` — первый запуск без Actions, сборка на ВМ, Caddy и HTTPS.
`GITHUB_ACTIONS_MIGRATION.md` и `github-actions.html` — переход после ручного
запуска. Сохранять baseline работающего образа перед первым auto release:
без current скрипт не знает предыдущую ручную версию. Caddy и data не пересоздаются.
`manual-deployment.html` — автономная HTML-версия с подстановкой параметров,
копированием команд и ручными отметками прогресса. При изменении инструкции
синхронизировать все блоки команд; канонический источник — MANUAL_DEPLOYMENT.md.
Дизайн и ограничения HTML: deployment-guide.DESIGN.md. Не добавлять сетевую
отправку параметров, ввод секретов или автоматическое выполнение команд.
Сверять команды с compose.yaml, scripts/deploy.sh, workflow и шаблонами deploy/.
Указывать место выполнения: компьютер, администратор ВМ или пользователь deploy.
В ручном гайде локальные команды рассчитаны на WSL / Bash; SSH доступен именно
там. Windows-путь проекта соответствует /mnt/g/Edu/MacroDashboard. Сохранять
вариант с существующим SSH-алиасом, чтобы не требовать переноса ключей в Windows.
Секреты в примерах только пустые или placeholders. Не обещать zero downtime,
доступность источников или автоматический откат схемы SQLite.
