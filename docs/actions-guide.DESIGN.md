# HTML гайд перехода на Actions

Область: docs/github-actions.html. Наследует framed-sheet, IBM Plex Sans и поведение
из deployment-guide.DESIGN.md; основной интерфейс и ручной гайд не переделываются.
Канонический текст и 19 блоков кода — GITHUB_ACTIONS_MIGRATION.md.

Вопрос читателя: как перейти с уже работающей ВМ на автоматические релизы.
Схема master → Actions → ВМ подчёркивает сохранение Caddy, сертификатов и SQLite.
IP 158.160.231.174 и домен macro-dashboard.ru предварительно заполнены из контекста
пользователя; поле SSH-пользователя означает прежнего администратора, не deploy.
Отдельный ключ localStorage сохраняет прогресс этого гайда независимо от ручного.

Поля не принимают секреты. Содержимое приватного SSH-ключа переносится в GitHub
пользователем через локальный буфер; страница сама его не читает и не отправляет.
Блок dotenv подписан как содержимое файла конфигурации, остальные блоки — WSL/ВМ.
Все инструкции доступны без JavaScript; фоновых подключений к ВМ нет.

Синтаксис Bash и переход на baseline проверены в Linux-контейнере с подменённым
Docker: берётся работающий образ, повторная регистрация не перезаписывает current,
ошибка первого auto release возвращает локальный baseline. Реальная ВМ и GitHub
не изменялись. Браузерная визуальная проверка недоступна по прежнему ограничению
локального file URL; дизайн наследуется без изменений геометрии.
