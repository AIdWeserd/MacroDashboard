# Дизайн HTML инструкции

Область: только docs/manual-deployment.html. Основное приложение Streamlit
и существующие макеты интерфейса не изменяются.

Режим Read: пользователь открывает инструкцию рядом с SSH-терминалом и проходит
последовательность запуска Ubuntu → Docker → Caddy → HTTPS → загрузка данных.
Команды взяты из MANUAL_DEPLOYMENT.md, инфраструктура не симулируется как рабочая.
Локальное окружение пользователя — WSL / Bash, код Windows доступен через /mnt/g/.
Четыре локальных блока (SSH, отправка кода, туннель, backup) подписаны WSL;
остальные команды выполняются в SSH-сессии ВМ. Существующий SSH-алиас можно
использовать как vm_target без переноса ключей в Windows.

Выбран framed-sheet из design-taste-frontend, seed 393377862: светлая рамка вокруг
белого листа, тихая навигация, без теней, цвет только у действия и состояния.
Схема домен → Caddy → Streamlit с постоянной SQLite связывает страницу именно
с MacroDashboard. Номер шага обозначает порядок выполнения.

Токены: frame #eef2f5, surface #ffffff, raised #f5f7f9, text #17222d,
muted #56636e, accent #165dc1, success #19744f. Шрифт IBM Plex Sans 400/600
встроен в HTML вместе с открытой лицензией. Моноширинный системный шрифт — для кода.
Страница автономна: CSS, JavaScript и шрифт внутри, внешние ресурсы не загружаются.

IP, домен и SSH-пользователь локально меняют текст команд; значения проходят
проверку перед подстановкой. Unicode-домен нормализуется в punycode. Секреты
не запрашиваются. Локальное хранилище сохраняет параметры и ручные отметки,
ошибка localStorage не препятствует чтению. Копирование имеет запасной путь
для локальных файлов и выделение текста при запрете буфера.

На телефоне меню сворачивается, поля выстраиваются в колонку, длинные команды
и таблицы прокручиваются внутри своих блоков. При печати поля и навигация скрыты,
команды переносятся. Отключение JavaScript оставляет текст и исходные команды.

Проверено программно: соответствие 24 блоков команд, синтаксис JavaScript,
подстановки, отклонение некорректного ввода, punycode, прогресс, сброс,
сохранение, мобильное меню и Clipboard API. Визуальный просмотр в браузере
не выполнен: встроенный браузер отклонил локальный file URL по политике доступа.
